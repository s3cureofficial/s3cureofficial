# S³cure

We build security tools for people who run servers and Discord communities. You shouldn't have to write code to use them.

### Projects

**[S3cure SSH Client](https://github.com/s3cureofficial/s3cure-ssh-client)**<br>
An SSH and SFTP client for macOS, Windows and Linux. Terminal, file browser with drag and drop, editor and tunnels, all in one window. Free and open source.<br>
[Download](https://github.com/s3cureofficial/s3cure-ssh-client/releases/latest) · [Source](https://github.com/s3cureofficial/s3cure-ssh-client)

**S³cure for Discord**<br>
A Discord bot that stops scams and raids. It shows up with your name and avatar, and you don't need to write code or host anything yourself. You choose which protections are on, separately for each server.
